## 1. Принципы и рамки продукта

- [x] Разделять first-party self-hosted gateway и сторонние API; не помещать aLandi в список внешних провайдеров.
- [x] Не включать скрытую маршрутизацию на внешний сервис; межпровайдерный fallback только при явном согласии.
- [x] Держать UI пригодным для бесплатного статического хостинга; не добавлять обязательные runtime-зависимости, платные сервисы или backend-only обещания.

## 13. Исследовательская база и решения

### Подтверждённые внешние источники

1. **OpenAI Help Center — поиск чатов, проектов и файлов.** Поиск вынесен в sidebar, поддерживает типовые фильтры; это полезный паттерн для единой точки поиска по содержимому, но не основание копировать весь интерфейс ChatGPT.  
   https://help.openai.com/en/articles/10056348-finding-your-chats-projects-and-files-in-chatgpt
2. **OpenAI ChatGPT release notes.** В актуальном веб-интерфейсе есть pinning чатов и проектов, единая область Recents и группировка по проектам; заимствовать принцип организации и закрепления, сохранив понятную прямую навигацию aLandi.  
   https://help.openai.com/en/articles/6825453-chatgpt-release-notes
3. **Apple HIG — Text fields.** Placeholder помогает распознать назначение поля, но может исчезнуть после ввода; для важных полей нужен доступный label. Secure text field — для секретов.  
   https://developer.apple.com/design/human-interface-guidelines/text-fields
4. **W3C WCAG 2.2.** Проверять reflow на 320 CSS px, контраст, видимость фокуса, focus not obscured и target size. 24×24 CSS px — минимальный критерий AA с исключениями; 44 pt из Apple HIG — отдельная рекомендация, единицы не смешивать.  
   https://www.w3.org/TR/wcag/
5. **Material Design drawer guidance.** Для modal drawer — семантика dialog, focus trap, inert background; для обычной навигации — landmark navigation и явный current item.  
   https://m3.material.io/components/navigation-drawer/overview

### Принятые UX-решения для aLandi

- Заимствовать: поиск в одном узнаваемом месте, pinning важного, проектную группировку, progressive disclosure, единые состояния компонентов, sticky контекстные действия.
- Не заимствовать: тяжёлую многослойную навигацию, лишние переключатели режимов, неясные разделы «для экспертов», облачную зависимость, скрытые маршруты передачи данных.
- Приоритет: предсказуемость и автономность важнее визуальных эффектов; минимализм не должен уменьшать hit areas, контраст или доступность.
- Анимация ticker — только индикатор планов, не индикатор фоновой работы и не обещание доступности.
