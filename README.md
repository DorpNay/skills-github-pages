# AI Mobile Agent

Мобильный веб-интерфейс ИИ-ассистента, публикуемый через GitHub Pages.

**Сайт:** https://dorpnay.github.io/skills-github-pages/

## Первый запуск

1. Откройте сайт и нажмите **⚙️ Настройки**.
2. Поля **Base URL** и **Модель** уже заполнены рабочими параметрами Gemini:
   - Base URL: `https://generativelanguage.googleapis.com/v1beta/openai`
   - Model: `gemini-3.8-flash`
3. Откройте [Google AI Studio — API keys](https://aistudio.google.com/apikey), создайте свой Gemini API key и вставьте его в поле **API Key**. Не публикуйте этот ключ и не отправляйте его другим людям.
4. Нажмите **Сохранить**, закройте настройки и отправьте короткий тест: `Ответь одним словом: работает?`
5. Если меняли параметры и API перестал отвечать, нажмите **Восстановить параметры Gemini**, затем **Сохранить**. Эта кнопка восстанавливает URL, модель и системный промпт, но не стирает ваши API-ключи.
6. Переключатель **Веб-поиск** выключен по умолчанию. Для него нужен отдельный ключ [Tavily](https://app.tavily.com/home). Прямые запросы к Tavily из браузера могут блокироваться CORS; если это происходит, обычный чат продолжит работать, а поиск потребует серверного прокси.
7. **Мультиагентный стиль** добавляет этапы Planner → Researcher → Critic → Synthesizer в инструкции одной модели. Это не отдельные параллельные агенты и не фоновое выполнение.
8. Системный промпт отправляется с каждым API-вызовом (в том числе при продолжении поиска), потому что совместимый chat API не хранит состояние между вызовами. Он сделан коротким, чтобы накладные расходы были небольшими. История ограничена по числу сообщений и примерно по символам; в системный контекст попадают только тематически совпавшие заметки (не больше 4 и 1 200 символов).
9. Полноценное управление браузером через Browser Use или похожие проекты не включено: это требует отдельного локального/серверного процесса и прав доступа к браузеру. Для статического GitHub Pages такая интеграция добавила бы сложность и поверхность риска без гарантии совместимости.

## Что умеет приложение

- Чат с моделью через OpenAI-compatible Chat Completions API.
- Несколько локально сохранённых диалогов, экспорт и импорт истории.
- Локальная заметочная память с выбором заметок по совпадению с текущим запросом; нерелевантная память не отправляется модели.
- Компактный системный промпт с правилами проверки фактов, работы с инструментами и защиты от инструкций внутри найденных страниц/файлов.
- Ограничение истории примерно 24 000 символами и максимум 24 сообщения, чтобы старые диалоги не раздували каждый запрос.
- Кэш ответов и запуск Python через Pyodide в браузере.
- Отображение Markdown с очисткой HTML через DOMPurify.
- Отмена текущего запроса и повтор после ошибки.

## Важные ограничения и приватность

- Это статический сайт, у него **нет собственного сервера**. API-запросы отправляются из браузера напрямую выбранному провайдеру. Совместимость браузера, CORS, доступность модели, квоты и тарификация зависят от провайдера и вашей учётной записи.
- API-ключи, настройки, чаты и заметки хранятся в локальном хранилище/IndexedDB браузера на этом устройстве. Не сохраняйте ключи на общих устройствах. Очистка данных сайта может удалить историю и настройки; регулярно экспортируйте важные чаты.
- Не вставляйте в чат секреты, пароли, персональные или рабочие данные, которые нельзя передавать выбранному API-провайдеру.
- Gemini API может иметь бесплатные лимиты и платные тарифы; перед использованием проверьте актуальные условия в Google AI Studio.
- Python-код запускается в браузерной среде Pyodide, а не на сервере проекта. Это не полноценная удалённая ОС и не фоновый исполнитель задач.
- Веб-поиск через Tavily — необязательная функция; без ключа поиска не будет.

## Проверка и публикация

GitHub Pages собирает сайт из ветки `main`. После каждого изменения проверьте [Actions](https://github.com/DorpNay/skills-github-pages/actions) и дождитесь успешного workflow **pages build and deployment**. Затем откройте сайт в приватной вкладке или обновите его без кэша. Успешная сборка подтверждает публикацию Jekyll, но не заменяет проверку API-ключа и реального запроса в браузере.

## Сторонние библиотеки

Интерфейс использует Tailwind CSS, Marked, DOMPurify и Pyodide через CDN. Для работы требуется интернет-соединение.
