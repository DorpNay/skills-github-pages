## Проверка качества

GitHub Actions выполняет статические quality sentinels, сборку Jekyll и браузерные E2E-тесты в Chromium без настоящих API-ключей. E2E проверяют запуск интерфейса, переключение и сохранение ключей провайдеров, Tavily, режим обработки, сохранение чатов и отображение ошибки API 401. При падении workflow прикладывает Playwright trace/screenshot/video для разбора.

Локальный запуск E2E после установки Node.js и Playwright: `npm install --no-save @playwright/test@1.56.1`, `npx playwright install chromium`, затем сначала соберите сайт Jekyll в `_site`, и запустите `npx playwright test`.

## Первый запуск V1

1. Откройте [рабочий клиент](https://dorpnay.github.io/skills-github-pages/) или изучите [лендинг aLandi](https://dorpnay.github.io/skills-github-pages/landing/).
2. В настройках явно выберите маршрут и модель. Статический сайт не содержит общего hosted AI endpoint и не выдаёт бесплатные токены: для внешнего API нужны собственные credentials и соблюдение тарифов/лимитов выбранного поставщика.
3. Для личного self-hosted маршрута сначала пройдите [START_HERE_RU.md](docs/START_HERE_RU.md) и [PRE_LAUNCH_STACK_RU.md](docs/PRE_LAUNCH_STACK_RU.md). Не вводите gateway key, пока локальный FastAPI/Ollama и HTTPS Tunnel не проверены владельцем.
4. Для первой проверки используйте короткий несекретный prompt. Проверьте выбранный маршрут, модель и ответ; не используйте персональные или рабочие данные в непроверенном endpoint.
5. Веб-поиск настраивается независимо от объёма работы. Отсутствие ключа Tavily не отключает клиент: часть открытых источников может работать без него, но CORS, квоты и доступность конкретных API не гарантируются.
6. Быстрый/Тщательный режим управляет бюджетом выполнения; Обычный/Расширенный/Выключенный — доступом и шириной веб-поиска. Структурированный разбор — отдельный четырёхэтапный pipeline на выбранной модели, а не четыре независимых агента. Профиль задачи добавляет инструкции, но сам по себе не выдаёт инструменты или разрешения.

**Важно:** старые инструкции о заранее заполненном Gemini URL/model и кнопке восстановления Gemini не являются актуальной настройкой V1. Каталоги моделей и их доступность меняются; используйте текущий provider picker и проверку соединения.

## Что умеет приложение

- Чат с моделью через OpenAI-compatible Chat Completions API.
- Несколько локально сохранённых диалогов, экспорт и импорт истории.
- Локальная заметочная память с выбором заметок по совпадению с текущим запросом; нерелевантная память не отправляется модели.
- Компактный системный промпт с правилами проверки фактов, работы с инструментами и защиты от инструкций внутри найденных страниц/файлов.
- Адаптивная выборка целых ходов по контексту конкретной модели с резервом для системного промпта и ответа; фиксированного потолка 24 сообщения/24 000 символов нет. Если провайдер не сообщает окно, используется оценка 16K токенов. Реальный лимит модели, RAM и безопасные ограничения шлюза сохраняются.
- Кэш ответов и запуск Python через Pyodide в браузере. Python-библиотека загружается только после явного нажатия «Запустить» у блока Python, а не при открытии сайта.
- Отображение Markdown с очисткой HTML через DOMPurify.
- Отмена текущего запроса и повтор после ошибки.
- Ограниченный резервный маршрут не должен незаметно менять выбранные настройки; переход между разными провайдерами разрешается только явной настройкой и может передавать им текст запроса/контекст.
- Небольшие всплывающие уведомления вместо большинства старых системных alert-окон; настройки остаются открытыми после сохранения.

## Важные ограничения и приватность

- GitHub Pages публикует статический клиент, но не запускает inference. Запрос идёт к явно выбранному внешнему API либо к отдельно настроенному частному aLandi gateway. Для этих маршрутов различаются получатель данных, CORS, авторизация, квоты и стоимость.
- Сбой или автоматический резервный маршрут запроса не должен переписывать выбранные провайдера, модель и endpoint. Резервный маршрут действует только для текущего запроса.
- API-ключи и настройки хранятся в локальном хранилище браузера на этом устройстве, заметки — в IndexedDB, история — в локальном хранилище. Сам API-ключ отправляется только тому endpoint, к которому идёт конкретный запрос. Однако при автоматическом резервном переходе текст запроса и контекст могут быть отправлены другому провайдеру, если его ключ сохранён. Если это нежелательно, оставьте ключ только у выбранного провайдера. Не сохраняйте ключи на общих устройствах. Очистка данных сайта может удалить историю и настройки; регулярно экспортируйте важные чаты.
- Не вставляйте в чат секреты, пароли, персональные или рабочие данные, которые нельзя передавать выбранному API-провайдеру.
- У каждого внешнего поставщика свои тарифы, лимиты, политика хранения и доступность моделей. Проверяйте их непосредственно перед использованием; бесплатный статический UI не означает бесплатный inference.
- Python-код запускается в браузерной среде Pyodide, а не на сервере проекта. Это не полноценная удалённая ОС и не фоновый исполнитель задач.
- Общий веб-поиск через Tavily требует отдельного ключа; без него остаются специализированные публичные API. У каждого источника свои квоты и ограничения CORS; чтение произвольной страницы не гарантируется.

## Проверка и публикация

GitHub Pages собирает сайт из ветки `main`. После каждого изменения проверьте [Actions](https://github.com/DorpNay/skills-github-pages/actions) и дождитесь успешного workflow **pages build and deployment**. Затем откройте сайт в приватной вкладке или обновите его без кэша. Успешная сборка подтверждает публикацию Jekyll, но не заменяет проверку API-ключа и реального запроса в браузере.

## Режимы обработки и ресурсы по запросу

- **Быстро** — минимум дополнительной работы: не загружает skill-файлы, использует сокращённый поиск и допускает один раунд инструментов.
- **Глубоко** — выбирает один подходящий текстовый навык из `skills/`, добавляет его инструкции в контекст и разрешает больше раундов поиска/инструментов.
- **Мультиагентное исследование** — отдельный переключатель с четырьмя последовательными вызовами модели: план → исследовательский черновик → критика → синтез. Это не включается режимом «Глубоко» автоматически и не создаёт независимые модели/фоновые процессы.
- **Интернет и источники** — независимый переключатель. Tavily используется при наличии ключа; иначе агент может выбирать специализированные открытые API. Прямое чтение страниц зависит от CORS и ограничений сайта.
- **Hugging Face CLI** из отдельного руководства предназначен для coding-агентов, работающих в локальном терминале (поиск моделей, datasets, jobs, skills). Встраивать CLI в статический сайт не требуется: для браузера используется HF Inference Providers HTTP API с токеном.
- **Python/Pyodide** — библиотека JavaScript и среда WebAssembly загружаются только при явном запуске Python-блока. Обычный чат не скачивает тяжёлую среду Python.

## Независимые помощники качества

В репозитории работают четыре детерминированных **quality sentinels** — независимые проверки, запускаемые параллельно в GitHub Actions:

- **Integrity** — проверяет структуру HTML, наличие критических элементов интерфейса и синтаксис встроенного JavaScript без выполнения кода.
- **Security** — проверяет отсутствие очевидных ключей в исходниках, безопасный путь рендеринга Markdown и ограничения аргументов веб-поиска.
- **Context** — контролирует лимиты истории, памяти и циклов инструментов, а также компактность системного промпта.
- **Pages build** — собирает сайт Jekyll и проверяет получившийся `_site/index.html`.

Запуск локально при установленном Node.js 22 или новее:

```bash
node scripts/quality-agents.mjs integrity
node scripts/quality-agents.mjs security
node scripts/quality-agents.mjs context
```

Полная сборка Jekyll выполняется в GitHub Actions. Проверки не используют Gemini, не отправляют данные в сторонние сервисы, не требуют API-ключей и не добавляют нагрузку на устройство посетителя. Это не языковые субагенты: они ловят механические регрессии и дают проверяемые сигналы; смысловой аудит всё ещё требует отдельного решения модели или человека. Такой подход следует принципам «сначала детерминированные проверки», независимого ревью и явных исходов из открытых проектов [agent-skills](https://github.com/SteveVitali/agent-skills), [NEEDLE](https://github.com/jedarden/NEEDLE) и [Chunk](https://github.com/CircleCI-Public/chunk-cli), без установки их тяжёлых рантаймов.
